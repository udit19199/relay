Never hit empty mid task

Relay keeps your coding agent working when an AI plan hits its limit. It holds the Claude, Codex and OpenCode Go accounts you already pay for behind one local endpoint, and when one runs dry the next request goes to another plan in the order you set.

01 / how it works

One URL in. Every account out.

1

Point your tool at Relay

Claude Code, OpenCode, or any client that speaks the OpenAI, Anthropic or Gemini API. relay setup prints the two lines.

2

Relay picks an account

The next healthy one for that model. It translates the request into that provider's format.

3

Limit hit? Next one

On a rate limit that account rests, the request retries on another, and a fallback chain moves it to the next plan. The notch shows what is left.

429 → 200

Your tool sends one request and gets one answer. When a provider says an account is out, Relay rests it and retries the same request somewhere else, so the error never reaches the tool.

03 / install

Get it running

You need macOS and Homebrew. The proxy is built from source for now, and Homebrew installs Go as a build dependency.

If Relay already runs on this Mac, stop the old service first: launchctl bootout gui/$(id -u)/com.relay.proxy

# the formula lives in the relay repo
brew tap udit19199/relay https://github.com/udit19199/relay
brew install relay

# first run: config, keys, login service, then it starts
relay setup

# point a tool at it, lines printed by setup
export ANTHROPIC_BASE_URL=http://127.0.0.1:8317
export OPENAI_BASE_URL=http://127.0.0.1:8317/v1

Without Homebrew: git clone https://github.com/udit19199/relay, then go build -o ~/.local/bin/relay ./cmd/server and relay setup. The notch app is a separate Swift build.
