How it works

Relay is a small server on 127.0.0.1:8317. Your tools talk to it instead of to Anthropic or OpenAI.

Your tool sends a request

Claude Code, OpenCode, or anything that speaks the OpenAI, Anthropic, or Gemini API.

Relay picks an account

It takes the next healthy account for that model and translates the request into that provider's format.

A limit hits, it moves on

On a rate limit, Relay rests that account and retries on another one. Your session keeps going.

Speaks every common format

Streaming and tool calls work in all of them. A Gemini-format request can go to a Claude account, and an Anthropic-format request can go to OpenCode Go.

Install

macOS, Go 1.26 or newer, and Xcode command line tools. No prebuilt downloads yet.

# build the proxy
git clone https://github.com/udit19199/relay.git && cd relay
go build -o ~/.local/bin/relay ./cmd/server

# sign in, then start it
relay --config ~/.relay/config.yaml --claude-login
relay --config ~/.relay/config.yaml

# build the notch app
cd notch && ./scripts/package-local-app.sh
# point Claude Code at it
export ANTHROPIC_BASE_URL=http://127.0.0.1:8317
export ANTHROPIC_AUTH_TOKEN=your-client-key

The README has the full config and the management key step.

Before you use it

Relay signs in with your own accounts, the same way the official command line tools do. Providers may not allow this in their terms and can limit or close accounts that do it. Use accounts you are willing to risk.
